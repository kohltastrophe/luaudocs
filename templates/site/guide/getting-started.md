# Getting Started

Welcome to the **@TITLE@** documentation.

This page is yours: edit `guide/getting-started.md` next to this site's
`index.md`. Add more pages to that `guide/` directory and the sidebar picks
them up, labeled and ordered by the `title` and `sidebar_position`
frontmatter at the top of each file.

The [API Reference](/api/) is generated from your Luau source by
[LuauDocs](https://luaudocs.kohl.gg): the signatures come from the
annotations already in your code, and a doc comment (`--[[ like this ]]` or
`--- like this`) above a definition becomes its description. See
[Writing Doc Comments](https://luaudocs.kohl.gg/guide/writing-doc-comments)
for the prose layer on top.
